# 🚀 AR Portfolio Project (Unity + Vuforia)

This project combines:
- AR Business Card (with 3D text, intro video, LinkedIn & GitHub links)

## 🎥 Demo
https://github.com/Tanish-Ahmed/AR-Portfolio-vuforia/blob/main/ar%20business%20card%20demo%20.mp4

## 🛠 Tools
- Unity 6
- Vuforia Engine
- C#

## 📌 Setup
1. Clone repo
2. Open in Unity
3. Import Vuforia SDK
4. Replace target images with your own
5. Build to Android/iOS
